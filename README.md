# Pharma Monograph Extractor

A comprehensive tool for extracting structured data from pharmaceutical product monographs using AI and pattern matching.

## Features

Extracts the following information from PDF monographs:

- **Metadata**: Brand name, company, initial authorization, revision date, ingredients, dosage
- **Indications**: Conditions the drug treats (comma-separated)
- **Contraindications**: Conditions where drug should not be used
- **Serious Warnings**: Core warning topics from the Serious Warnings box
- **Adverse Events**: List of adverse reactions
- **Drug Interactions**: Interacting drugs and classes
- **Organ Impairment Dosing**: Liver and kidney dose adjustments
- **Pharmacokinetics**: Comprehensive summary paragraph
- **Metabolism**: CYP enzyme information
- **Elimination**: Urine and faeces excretion percentages
- **Pharmacodynamics**: Mechanism of action summary
- **Pregnancy**: Recommendation status and summary
- **Breastfeeding**: Recommendation status and summary
